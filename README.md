# Raritone 3D Asset Generation & Validation Pipeline

Prototype pipeline for generating, validating, reviewing,
optimizing, and managing 3D product assets for Raritone.

## Pipeline

Product Image
→ 3D Generation
→ Candidate Asset
→ Validation
→ Human Review
→ Approval
→ Optimization
→ Raritone 3D Catalog

## Current Generation Method

Manual Image-to-3D generation.

## Planned Automation

Meshy API integration will be added later.

## Asset Types

- T-shirt
- Shoe
- Watch
- Handbag
- Jewellery
